# Прикладная логика

Здесь размещаются сценарии приложения: получение данных из интеграций,
обработка и подготовка результата для HTTP-обработчиков.

Определяйте необходимые сценарию небольшие интерфейсы интеграций
в этом пакете. Конкретные клиенты передавайте через
конструктор сервиса. Связывайте зависимости в `cmd/api/main.go`.

Первый сценарий реализован в `ticktick.go`: получение проектов и сбор их задач
с общим таймаутом операции. Интерфейс `TickTickProvider` позволяет проверять
сценарий без запросов к реальному API.
