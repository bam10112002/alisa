# Интеграции

Для каждого внешнего сервиса создавайте отдельный пакет, например
`internal/integrations/weather`. В нём размещайте клиент API, модели запросов
и ответов, обработку ошибок провайдера.

Создавайте HTTP-клиенты с явным таймаутом и переиспользуйте их.
Передавайте `context.Context` из HTTP-запроса в методы интеграций и создавайте
исходящие запросы через `http.NewRequestWithContext`.

Секреты и адреса провайдеров добавляйте в конфигурацию через переменные
окружения. Клиенты не должны зависеть от HTTP-обработчиков приложения.
